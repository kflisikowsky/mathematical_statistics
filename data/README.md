# Survey data used in Chapter 5

`student-mat.csv` is the mathematics-course file from the UCI Machine Learning Repository's [Student Performance dataset](https://archive.ics.uci.edu/dataset/320/student+performance). It is the original semicolon-separated CSV from the UCI download archive.

The dataset describes secondary-school students from two schools in Portugal. The variables used in the example are `address` (urban or rural) and `internet` (home internet access, yes or no). The UCI record includes the dataset description, citation information, and download links.

When reusing the dataset, cite the UCI repository record and its original authors as directed on that page.
